# 가이드 섹션 오픈 디자인

## 목적

계산기 중심 사이트 구조를 유지하면서, 검색 유입과 사용자 신뢰도를 함께 높이기 위한 별도 가이드 섹션을 연다.
첫 가이드는 물타기 계산기와 직접 연결되는 설명형 콘텐츠로 시작한다.

## 범위

- 가이드 목록 페이지: `/guides`
- 첫 상세 가이드 페이지: `/guides/averaging-down`
- 연결 대상 계산기: `/calculators/multa`

이번 단계에서는 가이드 섹션의 정보 구조와 첫 콘텐츠 기준만 확정한다.
뉴스, 종목 허브, 장문 블로그형 확장은 포함하지 않는다.

## 정보 구조

### `/guides`

- 역할: 설명형 콘텐츠 허브
- 목적: 계산기를 더 잘 이해하고 활용하기 위한 가이드를 한곳에서 탐색하게 한다.
- 구성:
  - 섹션 소개
  - 가이드 카드 목록
  - 각 카드에서 관련 계산기로 이어지는 맥락 표시

### `/guides/averaging-down`

- 역할: 첫 검색 유입용 상세 가이드
- 주 키워드: `물타기 계산법`, `물타기 계산기`
- 목적:
  - 물타기의 개념을 짧고 명확하게 설명
  - 평단가가 어떻게 바뀌는지 예시로 이해시키기
  - 최종적으로 계산기 사용으로 자연스럽게 연결

## 콘텐츠 원칙

첫 가이드는 짧지만 신뢰도 있는 톤으로 작성한다.

- 너무 긴 이론 설명보다 실제 사용 맥락을 우선한다.
- 계산 원리를 한 번은 보여주되 수식 설명만으로 끝내지 않는다.
- 숫자 예시를 포함해 초보 사용자도 바로 이해할 수 있게 한다.
- 과한 투자 조언처럼 보이지 않게 주의사항을 포함한다.
- 본문 안과 하단 CTA에서 모두 계산기 링크를 제공한다.

## 첫 가이드 권장 구성

1. 물타기 계산이 무엇인지
2. 언제 계산이 필요한지
3. 평단가가 바뀌는 원리
4. 간단한 숫자 예시
5. 주의사항
6. `물타기 계산기 바로 사용하기` CTA

## 내부 링크 전략

- 홈 또는 가이드 허브에서 첫 가이드로 진입 가능해야 한다.
- 물타기 계산기 페이지에서는 이 가이드로 이동할 수 있어야 한다.
- 가이드 상세 페이지에서는 물타기 계산기로 돌아가는 CTA를 명확히 노출한다.

핵심 흐름은 다음과 같다.

`검색 -> 가이드 -> 계산기 -> 관련 계산기`

## 메타데이터 원칙

- `/guides`
  - title 예시: `투자 계산 가이드 모음`
  - description 예시: `물타기, 배당, 수익률 계산기를 더 잘 이해하기 위한 설명형 가이드 모음입니다.`

- `/guides/averaging-down`
  - title 예시: `물타기 계산법: 평단가가 어떻게 바뀌는지 쉽게 이해하기`
  - description 예시: `물타기 계산법과 평단가 변화를 예시로 설명하고, 물타기 계산기로 바로 확인할 수 있게 안내합니다.`

## 구현 전 확인 기준

- 가이드 URL은 단수 `guide`가 아니라 복수 `guides`로 통일한다.
- 첫 상세 가이드는 물타기 계산기와 직접 연결되는 주제로 시작한다.
- 가이드는 계산기를 대체하지 않고 계산기 사용을 돕는 보조 자산으로 유지한다.
