# 주식 계산기 & 정보 허브 — Lean Canvas

| 칸 | 내용 |
|----|------|
| **문제** | 1. 물타기·배당·수익률·손절가 같은 투자 계산을 위해 엑셀이나 여러 사이트를 전전해야 한다 2. 기존 서비스는 로그인·설치 등 진입 장벽이 높다 3. 입문자는 계산 방법 자체를 모른다 |
| **고객 세그먼트** | 국내 개인 투자자 (입문자~중급, 모바일+PC 사용자) |
| **고유 가치 제안** | 로그인 없이 바로 쓰는 주식 계산기 — 필요한 도구만, 빠르게 |
| **솔루션** | 물타기/배당/적정가에 더해 수익률, 목표가/손절가, 추가 매수 필요 금액, 복리 수익, 배당 재투자 계산기를 독립 URL 페이지로 제공. 계산기 페이지에는 짧은 설명 섹션을 두고, 다음 단계에서 별도 `/guides` 섹션을 열어 물타기 계산법 같은 설명형 콘텐츠를 연결 |
| **채널** | 구글 SEO (키워드: "물타기 계산기", "물타기 계산법", "배당 계산기", "적정주가 계산기", "주식 수익률 계산기", "손절가 계산기") → 초기 유입은 검색 중심으로 확보 |
| **수익 모델** | Google AdSense (페이지뷰 기반 광고 수익) |
| **비용 구조** | 도메인 + 호스팅 (Vercel 무료티어 가능), 개발 시간, 뉴스 연동 시 외부 API 비용 |
| **핵심 지표** | 월간 페이지뷰 목표: 3개월 내 5,000 PV / 6개월 내 30,000 PV (애드센스 수익 발생 기준) |
| **경쟁 우위** | 계산기별 독립 SEO 페이지 구조 + 계산기와 직접 연결되는 가이드 섹션 + 지속적 도구 추가 → 시간이 지날수록 검색 키워드 점유 확대 |
