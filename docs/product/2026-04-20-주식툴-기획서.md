# 주식 계산기 & 정보 허브 — 제품 기획서

## WHO — 누구를 위한 제품인가

```
이름: 김개미 (가상)
상황: 직장을 다니며 짬짬이 주식 투자 중인 2~5년차 개인투자자.
      입문자부터 중급까지 포함.
목표: 손실 최소화, 배당 수익 확보, 종목 적정가 파악
고통: 필요한 계산을 할 때마다 엑셀을 켜거나 여러 사이트를
      돌아다녀야 한다. 증권사 앱은 기능이 너무 많아 복잡하다.
현재 해결 방식: 직접 계산, 네이버 증권 + 엑셀 병행,
              유튜브/블로그 검색으로 때움
```

## WHAT — 어떤 문제를 푸는가

**Problem Statement**
> 개인 투자자는 투자 판단이 필요한 순간마다 계산기·뉴스·배당정보를 따로따로 찾아야 한다. 왜냐하면 기존 서비스들이 "모든 기능을 한 앱에" 전략으로 만들어져, 단순한 계산 하나를 위해서도 회원가입·앱설치·복잡한 UI를 거쳐야 하기 때문이다.

**JTBD**
> 김개미는 투자 결정이 필요한 순간에, 빠르게 계산하고 정보를 확인하기 위해 이 사이트를 고용한다. 로그인 없이 바로 쓸 수 있어야 한다.

**기존 서비스가 실패하는 이유**
- 네이버 증권 / 증권사 앱: 기능 과잉, 로그인 필요, 단순 계산 접근이 불편
- 기존 계산기 사이트: 단일 기능, 디자인 낙후, SEO 최적화 미흡

## HOW — 어떻게 해결하는가

**선택 방향:** 계산기 특화 사이트 (방향 A) — 각 계산기를 독립 페이지로 SEO 최적화

**플랫폼:** 웹 (모바일 + PC 반응형)

**구조 원칙:**
- 로그인 없음, 즉시 사용 가능
- 계산기와 정보 페이지를 독립 URL로 분리 → 각 페이지가 독립적으로 구글 검색 유입
- 새 계산기/정보 페이지를 소수 파일 수정만으로 확장할 수 있는 템플릿 구조
- 각 페이지에 애드센스 광고 슬롯 포함

**MVP 기능 목록 (Must)**

| # | 기능 | SEO 타겟 키워드 |
|---|------|----------------|
| 1 | 물타기 계산기 | "물타기 계산기", "주식 평단가 계산" |
| 2 | 배당 계산기 | "배당 계산기", "배당수익률 계산" |
| 3 | 적정가 계산기 | "적정주가 계산기", "PER PBR 계산" |
| 4 | 수익률 계산기 | "주식 수익률 계산기", "평가손익 계산" |
| 5 | 목표가/손절가 계산기 | "손절가 계산기", "목표가 계산기" |
| 6 | 추가 매수 필요 금액 계산기 | "목표 평단가 계산", "추가매수 계산기" |
| 7 | 복리 수익 계산기 | "복리 계산기", "투자 복리 계산" |

| 9 | 홈 페이지 | "주식 계산기 모음", "주식 투자 도구" |
| 10 | 확장 가능한 라우팅·레이아웃 구조 | (인프라) |
| 11 | 애드센스 슬롯 배치 | (수익화) |

**MVP 포함 기준**
- 이번 버전은 계산기 8종, 홈 페이지, 공통 레이아웃, 기본 광고 슬롯까지 포함
- 각 계산기 페이지에는 결과 이해를 돕는 짧은 설명 섹션을 유지
- 별도 설명형 콘텐츠는 다음 단계에서 `/guides` 섹션으로 분리해 추가
- 뉴스/배당주 정보 페이지는 이번 버전에 포함하지 않음

**이번 단계에서 추가하는 계산기 5종**
- 수익률 계산기: 매수단가, 현재가, 수량 기준 평가손익과 수익률 계산
- 목표가/손절가 계산기: 진입가 기준 목표 수익률/손절률에 대응하는 가격 계산
- 추가 매수 필요 금액 계산기: 목표 평단가까지 낮추기 위해 필요한 추가 매수 금액과 수량 계산
- 복리 수익 계산기: 초기금액, 월 적립액, 기대 수익률, 기간 기반 미래 자산 계산
- 배당 재투자 계산기: 배당금을 재투자할 때 보유 수량과 예상 자산 증가 계산

**Should (다음 단계 확장)**
- `/guides` 목록 페이지 오픈
- 첫 상세 가이드 `/guides/averaging-down` 작성
- 계산기 페이지와 가이드의 상호 링크 연결
- 최신 뉴스 정리 페이지
- 배당주 정보 페이지

**Could (이후 확장)**
- 배당 캘린더
- 종목 재무 요약
- 환율·금리 등 추가 계산기

- 로그인 / 회원가입
- 포트폴리오 저장 기능
- 실시간 시세 API 연동 (비용 발생)
- 커뮤니티 / 댓글 기능
